# 无畏契约专属灵敏度生成器 — 设计规格

日期：2026-08-14
状态：已批准（算法选定方案二：迭代校准）

## 1. 目标与范围

为用户生成**当前版本无畏契约中可直接输入使用的灵敏度数值**（游戏灵敏度区间 [0.001, 10]，3 位小数，如 `0.314`），生成过程基于内嵌测试的实际表现，而非拍脑袋公式。

**交付物**：单个离线 HTML 文件 `valorant-sens-generator.html`，零外部依赖（无 CDN、无框架），双击即用，全中文界面，无畏契约红黑主题。

**用户档案（已确认）**：800 DPI、混合流（手臂大转向 + 手腕微调）、45cm 鼠标垫（L 码）。

**硬性要求（用户强调）**：
1. Aimlabs 式网格射击目标**鼠标移动碰到即触发，全程无需点击**
2. 测试中隐藏系统光标，绘制**自定义准星**跟随鼠标
3. 倒计时**必须正常流动、绝不卡死**（含切标签页场景）
4. 测试内嵌在页面中，不是外链
5. 输出值在游戏里输入即可应用（当前版本格式）

## 2. 页面流程（四步）

1. **习惯档案**：DPI、鼠标垫宽、垫宽转身角度（180°/270°/360°，默认 180°）、瞄准风格（默认混合流）
2. **物理校准**：按住拖动一条线移动鼠标 10cm → 实测 px/cm 换算比（吸收 Windows 系统灵敏度差异）
3. **测试中心**：迭代校准（最多 3 轮，每轮 4 项短版测试，轮间自动调整灵敏度）
4. **专属灵敏度报告**：最终数值 + 游戏设置指引 + 成绩图表

## 3. 单文件内部模块划分

| 模块 | 职责 | 接口 |
|---|---|---|
| ProfileStore | 档案表单 + localStorage 读写 | `getProfile() / saveProfile(p)` |
| Calibrator | px/cm 校准测量与默认回退 | `calibrate(): Promise<pxPerCm>` |

## 4. 数学与换算（游戏↔网页映射）

无畏契约引擎：每鼠标计数旋转 0.07 × sens 度。

- `度/厘米 = 0.07 × sens × DPI / 2.54`
- `cm/360 = 914.4 / (0.07 × DPI × sens)`（800 DPI、sens 0.3 → 54.4cm/360，与职业常识一致 ✓）
- **基准灵敏度**（一整垫 = 所选转身角度）：`sens0 = 角度 × 2.54 / (0.07 × DPI × 垫宽cm)`
  - 800 DPI / 45cm / 180° → sens0 ≈ 0.181（eDPI 145，低敏起点，交给迭代上调）
- **网页像素换算**：`px/度 = pxPerCm × 2.54 / (0.07 × sens × DPI)`。目标按**角度**摆位（如网格间距 12°、闪点距离 15–60°），再渲染成像素，保证与游戏物理一致
- 校准默认回退：37.8 px/cm（Windows 96 DPI 典型值），未校准时有警示横幅
- 页面提示：测试前关闭 Windows「提高指针精确度」（游戏用原始输入不受影响，但测试受系统加速度影响）

## 5. 四项测试规格（每轮短版）

每测试前 3-2-1 开场倒计时；每轮总耗时约 65 秒 + 倒计时。

| 测试 | 玩法 | 时长 | 指标 |
|---|---|---|---|
| 网格射击 | 3×3 网格（间距 12°）随机亮靶，**碰触即爆** | 20s | 命中数、平均接靶时间、过冲率（爆靶前越过靶心 >2°） |
| 跟枪追踪 | 目标沿正弦叠加平滑随机游走 | 15s | 平均偏差（px→度）、抖动度（方向变化方差） |
| 微调精度 | 8–14px 小目标、随机偏移 3–7° | 15s | 命中率、平均修正时间 |
| 反射闪点 | 随机位置目标闪现 700ms | 15s | 反应时间、命中率、甩枪末段偏差（末段停在靶心后 >2° 记欠冲、越过 >2° 记过冲，据此计算过冲率/欠冲率） |

**倒计时实现（关键）**：`requestAnimationFrame` 循环 + `performance.now()` 时间戳差值驱动剩余时间，**不用 setInterval 递减计数器**；`visibilitychange` 时自动暂停并缓存已用时间，回来显示「已暂停，点击继续」。保证任何情况下倒计时不冻结、不跳变。

**准星实现**：测试区 `cursor: none`，rAF 中在鼠标坐标绘制无畏契约同款绿十字（4 条线 + 黑描边 + 中心点），随 mousemove 实时更新。

**碰触触发**：mousemove 事件中检测鼠标与目标圆心距离 ≤ 目标半径即爆靶，无需任何点击。

## 6. 迭代校准算法（方案二）

- **R0**：基准灵敏度 sens0（见 §4）
- **R1–R3**：每轮跑 4 项测试 → 指标合成修正系数：
  - 甩枪类（网格+闪点）过冲率 > 45% → 灵敏度 ×(1 − 0.15/轮次)；欠冲率 > 45% → ×(1 + 0.15/轮次)
  - 追踪平均偏差 > 2° → ×0.95；< 0.8° 且闪点命中率 > 60% → ×1.03
  - 微调命中率 > 80% 且甩枪不过冲 → ×1.05（允许上调）
- **步长随轮次衰减**：第 1 轮 ≤15%，第 2 轮 ≤8%，第 3 轮 ≤4%
- **收敛判定**：|Δsens| < 0.005 或 综合得分提升 < 2% → 提前停止；3 轮硬上限
- **综合得分**（混合流权重）：甩枪类 50%（网格 30 + 闪点 20）、追踪 30%、微调 20%，各指标归一化 0–100
- **最终处理**：四舍五入到 3 位小数 → 钳制 [0.001, 10]（越界时钳制并在报告注明）→ 每轮轨迹（灵敏度 + 得分）供收敛曲线图

## 7. 结果报告

- 大号灵敏度数字（如 `0.363`）+ 一键复制
- eDPI、cm/360、一整垫转身角度验证
- 职业区间参考：eDPI 150–450 常见，250–400 主流（注明非绝对，仅供参考）
- 瞄准镜倍率建议：固定推荐 1.0（说明可自行微调）
- 游戏内设置步骤：设置 → 鼠标 → 灵敏度：瞄准 → 输入数值；同时提醒 Windows 关闭鼠标加速
- 收敛曲线折线图（内联 SVG）+ 测试成绩雷达图（内联 SVG）
- localStorage 保存档案与历史结果

## 8. 错误处理与边界

- 未填 DPI / 垫宽 → 阻止进入测试并提示
- 跳过校准 → 默认 37.8 px/cm + 警示横幅
- 测试中途退出 → 该轮数据作废，返回测试中心
- 切标签页 / 失焦 → 自动暂停计时，恢复后手动继续
- 灵敏度越界 → 钳制 + 报告说明
- 不使用 Pointer Lock（普通 mousemove，规避浏览器兼容问题）；测试区屏蔽右键菜单与文本选择

## 9. 验证清单（交付前逐项过）

4. 准星：测试中系统光标隐藏、准星跟随流畅
5. 完整流程跑通：档案 → 校准 → 多轮测试 → 报告生成
